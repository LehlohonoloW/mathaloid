## Curriculum lenses
Atlas content is a single skill graph viewed through a **lens** (Settings → Lens). The lens changes labels, emphasis and exam style — not the mathematics.
| Lens | Coverage |
| --- | --- |
| CAPS (South Africa) | Grade 1–12, matric exam style |
| IEB | Grade 1–12 with extended problem-solving emphasis |
| Cambridge A-Levels | AS/A2 topics: calculus, further algebra, mechanics-flavoured applications |
| Global | Age-banded generic curriculum for anyone, anywhere |
## The five dimensions
Every recorded answer scores one or more dimensions, so “knowing” is measured five ways:
1. **Understand** — can you explain the idea?
2. **Fluent** — can you do it quickly and accurately?
3. **Apply** — can you use it inside a word problem?
4. **Reason** — can you justify and generalise?
5. **Create** — can you build something with it (Frontier)?
Data Desk draws these as a radar so learners see *shape*, not just score.
## Mastery bands
| Band | Meaning | Colour |
| --- | --- | --- |
| Secure | Ready to advance; enters long-interval review | green |
| Practising | Active learning zone | cyan |
| Review | Slipping — scheduled for reinforcement | amber |
| Foundation | Needs reteaching from the lesson model | pink |
## Spaced repetition
The Engine schedules each skill on expanding intervals; wrong answers shrink the interval, right answers grow it. The Pathfinder and “quiz me” chat intent both draw from the due-for-review queue first, so revision happens invisibly inside play.
## No ceiling, by design
Grade settings shape *defaults*, never *limits*: every tab remains browsable at every grade, and Frontier deliberately reaches past the syllabus (coding, simulation, modelling) so the atlas always has an open edge.
