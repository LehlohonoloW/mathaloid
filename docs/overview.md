## What is MATHALOID Atlas?
MATHALOID Atlas is an open source (MIT), privacy-first mathematics learning companion that runs entirely in your browser as a single static site. It teaches, drills and guides mathematics from **Grade 1 to Matric and beyond into A-Levels** — no account, no server, no tracking, no ceiling.
> No ceilings. No limits. Just mathematics.
## Who it is for
| Audience | What Atlas gives them |
| --- | --- |
| Learners (age 6–19+) | Adaptive lessons, games, quizzes and a personal mastery map |
| Parents | A safe, offline-capable tutor with zero data collection |
| Teachers | CAPS / IEB / A-Level lenses, exam simulator, classroom drills |
| Contributors | A zero-dependency codebase that is easy to read, fork and extend |
## The three promises
1. **Local-first** — everything (progress, settings, XP) lives in your browser's localStorage. The site works from a file, a USB stick or GitHub Pages.
2. **Privacy-first** — the app makes zero network requests after load. The AI tutor (Mathaloid Brain) runs 100% on-device. See [Security & privacy](security-privacy.md).
3. **No ceiling** — content is organised by curriculum lenses (CAPS, IEB, Cambridge A-Levels, Global) so a curious Grade 4 learner can wander into algebra, and a matriculant can push into calculus.
## Every tab, one atlas
| Tab | Purpose |
| --- | --- |
| Home | Cosmic hub — mascot, chat tutor, mission widgets |
| Pathfinder | Placement + recommended route through the atlas |
| Learn | Guided lessons with worked models |
| Play | Skill games (arcade-style drills) |
| Journey | Visual progress map across the maths universe |
| Study | Concept cards by category |
| Exam | Timed exam simulator with CAPS/IEB/A-Level style papers |
| Arena | Streak-based challenge mode |
| Data Desk | Your own learning analytics (radar, bands, history) |
| Frontier | Beyond-the-syllabus explorations (code, simulate, model) |
| Passport | XP, badges and identity |
| Voice | Speech input for the tutor |
| Settings | Grade, lens, theme, data export/erase |
| Help | How to use everything |
